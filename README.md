# 師生同步出題（live-class-quiz）

老師在電腦上載入題庫、設定出題方式，學生用平板掃 QR code 加入，全班跟著老師的節奏同步作答。

## 主要功能

- 載入題庫檔：Claude 轉好的 .json，或照 `samples/題庫範本.docx` 格式寫的 Word 檔；可按按鈕選檔，也可直接把檔案拖拉進設定畫面；可同時載入多份；有「預覽全部題目」可在上課前檢查題目與圖片。
- 依題型設定這次出幾題、每題作答時間或無限時；題目隨機抽出。
- 「出過的題目先不再出，等全部都出過才重新開始」，紀錄只保留到關閉工具為止。
- 出題順序可選「亂序出題」（抽到的題目全部打亂，不分題型）或「依序出題」（照題庫檔原本的順序）。
- 題組（例如閱讀測驗）整組一起考，小題照順序作答；計分時每個小題各算一題。
- QR code 加上每次不同的 4 位數認證碼；學生代號只能用英文或數字。
- 手寫題使用田字格，每格各有鉛筆、橡皮擦、復原、全部清除；格數依答案字數決定，造詞題由學生自選 2～4 格。造句、作文打字作答；選擇題點選後要按「確認送出」。
- 老師可進入任一學生的手寫板協助教學（紅筆）：老師與學生的筆劃分開管理，學生擦不掉老師的筆劃；老師可分別清除學生或老師的筆劃，並開關該學生的畫筆。
- 老師可一鍵暫停／開放全班作答，也可單獨暫停某位學生。
- 時間到或公布答案時，寫國字、改錯字、寫注音的田字格裡會疊上半透明的楷體範字（全字庫正楷體），對照筆劃位置；老師可以開關。
- 公布答案時，若題庫有詳解（`explanation`／`詳解`／`解析`），師生畫面會一起顯示。
- 畫面主題：護眼模式、馬卡龍、淡雅鵝黃；學生端跟著老師的選擇切換。
- 老師畫面即時看到全部學生的縮圖，可一鍵全開、一鍵全遮或單獨點選遮蔽。
- 延長時間（+10／+20／+30 秒，可連按）、直接結束作答並在師生畫面公布答案。
- 手寫與造句由老師點「對／錯」，選擇題自動批改；可「未批改的全部標對」。
- 提早結束：分數 = 答對題數 ÷ 已經考過的題數 × 100。
- 成績表可點題號看完整題目與每位學生的作答，並下載 Excel 試算表（成績、題目與統計、學生作答內容）。
- 寫國字的部件提示：老師按「部件提示」開放後，學生每格旁邊出現 💡，點開會看到依教育部標準筆劃畫出的部件卡（混入 2～3 個干擾部件、順序打亂，可點卡片變灰排除）；拆不開的字顯示筆畫數＋前兩筆。部件資料來自共用的 `andice0107/hanzi-component-detective`（`hanzi_parts_strokes.json`）。老師看得到誰看過提示，成績表與試算表也會標示。
- `docs/給AI的使用與轉檔說明.md`：交給 AI agent 看的說明，內容包括怎麼引導老師使用、怎麼把考卷轉成題庫檔。老師端也有下載按鈕。

## 題庫格式

```json
{
  "title": "第三課",
  "items": [
    { "type": "寫國字", "prompt": "看注音寫國字：ㄆㄥˊ ㄧㄡˇ", "answer": "朋友" },
    { "type": "選擇題", "prompt": "……", "images": ["data:image/png;base64,..."], "options": ["甲", "乙", "丙"], "answer": "B" },
    { "type": "題組", "title": "閱讀測驗", "passage": "文章……", "questions": [
      { "type": "選擇題", "prompt": "……", "options": ["…", "…"], "answer": "A" },
      { "type": "造句", "prompt": "……", "answer": "參考答案" }
    ] }
  ]
}
```

題型：寫國字、寫注音、改錯字、選擇題、造詞、造句（照樣造句／短語造句／句型造句）、填充（打字、自動比對，多個答案用 `|` 分隔）、手寫作答、作文、題組。可加 `"time": 秒數` 指定單題時間、`"cells": 格數` 指定田字格數、`"explanation": "詳解"` 在公布答案時顯示。圖片直接內嵌在題庫檔中，維持原始畫質。

## 字型

`fonts/tw-kai/` 是數位發展部「全字庫正楷體」（TW-Kai）的常用字切片，依 SIL Open Font License 1.1 再散布（見該資料夾的 `LICENSE-OFL.txt`、`NOTICE.md`）。瀏覽器只會下載畫面上用到的那幾片。

## 隱私

- 題庫檔只在老師的瀏覽器中載入，不會放進這個儲存庫。
- 學生只用英數代號，不收集姓名。老師關閉工具時，Firebase 上這間教室的資料會一併刪除；成績只存在老師下載的試算表中。
