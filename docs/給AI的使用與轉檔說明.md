# 師生同步出題工具：給 AI agent 的使用與轉檔說明

> 這份文件寫給協助老師的 AI agent，例如 Claude、Codex、ChatGPT 或其他 agent。讀完後你應該知道：
> 1. 怎麼引導老師使用這個工具；
> 2. 要請老師提供什麼內容；
> 3. 要把考卷轉成什麼檔案給老師下載；
> 4. 老師拿到檔案後，怎麼拉進工具裡上課或測驗。
>
> 請一律用**繁體中文**、口語、步驟清楚地回覆老師。老師不是工程師，不要叫老師改程式或打指令。

---

## 1. 工具是什麼

- 老師端網址：<https://andice0107.github.io/live-class-quiz/teacher.html>
- 學生端不用另外開網址，學生用平板掃老師畫面上的 QR code 就能加入。

這是給國小老師上課用的「師生同步出題」網頁：

- 老師在電腦上載入題庫，學生用 iPad 加入，全班跟著老師的節奏一題一題作答。
- 題型：寫國字、寫注音、改錯字、選擇題、造詞、造句（含照樣造句）、填充、手寫作答、作文、題組（閱讀測驗）。
- 寫國字、寫注音、改錯字、造詞都在**田字格**手寫。造句、作文用打字。選擇題用點的，再按「確認送出」。
- 老師可以看到全班即時的作答縮圖，可以遮蔽、延長時間、直接結束作答、進入學生手寫板用紅筆協助、暫停作答。
- 寫國字可以開「部件提示」：學生按 💡 會看到這個字的部件卡，裡面混了 2～3 個干擾部件；拆不開的字只顯示筆畫數和前兩筆。
- 最後會有成績表：每位學生每題的對錯，點題號可以看完整題目，還能下載 Excel。

## 2. 引導老師使用的步驟

照這個順序帶老師操作：

1. **準備題庫檔**：老師把考卷給你，你轉成 `.json` 題庫檔讓老師下載。轉檔方式見第 3、4 節。
2. **打開老師端**：用電腦打開上面的網址。
3. **載入題庫**：把 `.json` 檔**直接拖拉到網頁上**，或按「選擇題庫檔」。
   - 可以一次載入好幾份。
   - 載入後按「預覽全部題目」，檢查題目、圖片和答案是否正確。
4. **出題設定**：
   - 每個題型填「這次出幾題」和「作答時間」，也可以勾「無限時」。
   - 選擇「出過的題目先不再出」或「允許重複」。這個紀錄只保留到關閉網頁為止。
   - 選擇「亂序出題」（抽到的題目全部打亂，不分題型）或「依序出題」（照題庫檔的原本順序）。
5. **建立教室**：按「建立教室並抽題」，畫面會出現 QR code 和 4 位數認證碼。
6. **學生加入**：學生用 iPad 掃 QR code，輸入認證碼和代號。代號**只能用英文或數字**，例如 A01，不要用學生姓名。
7. **上課出題**：
   - 按「開始第一題」。時間到或按「直接結束作答」，師生畫面都會公布答案（有詳解也會一起顯示）。
   - 手寫題由老師按「對／錯」批改；選擇題會自動批改。
   - 寫國字題可以按上方「部件提示」開放或關閉提示，每一題開始時預設是關閉的。
8. **看成績**：
   - 全部出完，或按「提早結束」，就會出現成績表。
   - 提早結束時，分數＝答對題數 ÷ 已出的題數 × 100。
   - 按「下載成績試算表」就能存成 Excel。

常見問題：

- **學生進不來**：確認學生掃的是這一次的 QR code、認證碼正確、代號沒有中文或符號。
- **想換題庫**：重新整理老師端網頁，重新載入題庫。注意這樣會關閉目前的教室。
- **老師的 Word 是照「Word 題庫範本」寫的**：可以直接把 `.docx` 拉進工具，不用轉檔。範本可以在老師端按「下載 Word 題庫範本」取得。

## 3. 要請老師提供什麼

- **考卷檔案**：doc、docx、pdf 都可以，也可以是照片或截圖。
- **科目和年級**，例如「四年級國語第 1-5 課」。
- 老師如果有特別需求，也一併問清楚，例如：
  - 只要某些題型；
  - 某題要限時；
  - 題組要放在一起。

不用問老師「要什麼格式」，一律由你轉成 `.json` 題庫檔交給老師下載。

如果考卷裡有你無法確定的內容，例如答案缺漏、題號錯亂、錯字，**先照最合理的方式轉**，在回覆裡列出來請老師確認，不要卡住不給檔案。

## 4. 轉檔：產出 `.json` 題庫檔

### 4.1 檔案規格

- 副檔名 `.json`，UTF-8 編碼。
- 檔名用老師看得懂的中文，例如 `四年級國語第1-5課題庫.json`。
- **一份考卷一個檔**。老師給兩份考卷，就給兩個檔。

```json
{
  "title": "四年級國語第1-5課題庫",
  "subject": "國語",
  "items": [ 題目, 題目, ... ]
}
```

### 4.2 每一題的欄位

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | 建議 | 題目代號，不可重複，例如 `第1課-國字-3` |
| `type` | ✔ | 題型，見下表 |
| `prompt` | ✔ | 題目文字，可以換行（`\n`） |
| `answer` | ✔ | 答案，各題型寫法見 4.3 |
| `explanation` | | 詳解或解析，公布答案時會顯示 |
| `options` | 選擇題必填 | 選項文字陣列，**不要**加 ①② 或 A、B |
| `images` | | 題目圖片陣列，用 `data:image/png;base64,...` 內嵌 |
| `time` | | 這一題的作答秒數，會覆蓋老師在畫面上設定的時間 |
| `cells` | | 田字格數，最多 10 格，通常不用寫 |

`type` 可以填：

| 題型 | 作答方式 |
|---|---|
| `寫國字` | 田字格手寫（看注音寫國字） |
| `寫注音` | 田字格手寫（看國字寫注音） |
| `改錯字` | 田字格手寫 |
| `選擇題` | 點選 |
| `造詞` | 田字格手寫，學生自選 2～4 格 |
| `造句`、`照樣造句` | 打字 |
| `填充` | 打字，自動比對 |
| `手寫作答` | 空白手寫板（例如數學計算） |
| `作文` | 打字 |
| `題組` | 見 4.4 |

### 4.3 各題型的轉法（照這些規則，學生和老師畫面才會正確）

**寫國字（看注音寫國字）**
- `prompt` 保留原句，要寫的地方保留「ㄅㄆㄇ」括號。
- 一句有好幾個空格時，在每個「」前面依序加 ①②③……，學生才知道第幾格寫哪一個。
- `answer`：每格一個字，用**空格**分開，例如 `"鷹 緩 滑 姿"`。格數會自動等於答案字數。
- 同一句裡有些空格是「看國字寫注音」時，答案可以國字和注音混著寫，每一格一個，例如 `"偷 ㄐㄧㄝˇ 招"`。
- 有多個空格時，建議加 `time`：空格數 × 20 秒，至少 30 秒。

**寫注音**
- 所有空格都是寫注音時才用這個題型。
- `answer` 每格一組注音，用空格分開，例如 `"ㄕㄨˊ ㄑㄧㄠˇ"`。

**改錯字**
- `prompt` 放原句或原段落。有好幾個錯字時，在後面加一行「（共 N 個錯字，依序寫出正確的字）」。
- `answer` 的寫法：
  - 有好幾個錯字時，只寫正確的字，用「、」分開，例如 `"鷹、緩"`；
  - 只有一個錯字時，也可以寫成 `"門→們"`，公布答案時田字格會疊上「→」後面的字當範字；
  - 不要寫成 `"鶯→鷹、援→緩"` 這種好幾組箭頭的寫法，範字會對不上。
- 建議加 `time`：30 ＋ 錯字數 × 20 秒。

**選擇題**
- `options` 是純文字陣列，例如 `["雷", "類", "螺", "樓"]`。
- `answer` 一定要用**英文字母** `"A"`～`"D"`。不要用數字，數字會被當成從 0 起算的位置。
- 原卷「（ ）」這類作答括號要拿掉。原卷的詳解放進 `explanation`。

**造句**
- 「滑行——」這類題目，`prompt` 寫成 `用「滑行」造句`，`answer` 放參考答案。

**照樣造句**
- `prompt` 寫成三行：
  ```
  照樣造句
  範例：無比（堅定）的（自信）
  仿寫：無比（　）的（　）
  ```
- `answer` 寫成把參考答案填進括號的完整句子，例如 `"無比（雀躍）的（心情）"`。

**填充**
- 打字作答會自動比對。可以接受的答案用 `|` 分開，例如 `"十二|12"`。

### 4.4 題組（閱讀測驗等）

```json
{
  "type": "題組",
  "title": "閱讀測驗：小狗回家",
  "passage": "文章內容……",
  "images": [],
  "questions": [
    { "type": "選擇題", "prompt": "……", "options": ["…", "…", "…", "…"], "answer": "B" },
    { "type": "造句", "prompt": "……", "answer": "參考答案" }
  ]
}
```

- 題組會整組一起出，小題照原本的順序，每個小題各算一題分數。

### 4.5 圖片

- 考卷裡的圖片要**照原樣**放進 `images`，用 base64 data URI 內嵌，例如 `data:image/png;base64,...`。
- 不要重畫、裁切、壓縮或改顏色，老師要求圖片呈現「原汁原味」。
- 選項是圖片時，`options` 改用物件寫：`{"text": "", "image": "data:image/png;base64,..."}`。
- EMF/WMF 格式瀏覽器顯示不了，要先轉成 PNG。

### 4.6 交檔前自我檢查

1. 檔案能被 JSON 解析，沒有多餘的逗號。
2. 題數和原卷一致，按題型算好數量。
3. 選擇題的 `answer` 都是字母，並且對得上選項。
4. 寫國字、寫注音的格數，也就是答案個數，和題目的空格數一致。
5. 把需要老師確認的地方列出來，例如原卷錯字、答案和題目對不上。

交檔時，在回覆裡告訴老師三件事：

- 一共幾題、各題型各幾題；
- 你判斷或修正了哪些地方；
- 下載後**直接拖拉進工具**就能用。

## 5. 部件提示（寫國字題）

工具會自動幫「寫國字」的每一格準備部件提示，資料來自共用的 repo `andice0107/hanzi-component-detective`：

| 檔案 | 內容 |
|---|---|
| `hanzi_parts_strokes.json` | 每個字第幾筆屬於哪個部件，工具用教育部標準筆劃畫出部件卡 |
| `部件提示原則.md` | 怎麼拆字、怎麼補字的完整規則，**轉國字題庫前必讀** |

轉寫國字題庫時要多做一步：

1. 列出題庫裡所有「寫國字」答案的國字；
2. 檢查這些字是否已經在 `hanzi_parts_strokes.json`；
3. 不在表裡的字，工具只會顯示「筆畫數＋前兩筆」。如果要有部件卡，就照「部件提示原則.md」補上拆法，做總圖給老師核對；**老師確認後**才上傳。

## 6. 一定要遵守

- **考卷和題庫檔不可以上傳到 GitHub 或任何公開的地方**，只交給老師下載。
- 不收集、不寫入學生姓名或任何個資。學生代號只用英數字。
- 不要修改工具網站本身。工具的功能已經固定，轉檔只需要產出 `.json`。
  - 如果老師想要新功能，請老師另外提出，並先讓老師確認做法。
- 老師的每一個新工具都要用新的 repo 和網址，不可以覆蓋現有網站。
